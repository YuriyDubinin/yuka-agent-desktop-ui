# Yuka Agent Desktop UI

Графическая «мордашка» для [Yuka Agent](../yuka-agent): чат на Electron в стиле
«живого стекла» с четырьмя темами по времени суток. Агент `yuka-agent` сам находит это
приложение рядом с собой, запускает его, здоровается через него и ведёт весь разговор
в окне. Ответы модели проявляются плавно, слово за словом, по мере генерации.

**Стек:** Electron 45 · Electron Forge 8 (упаковка) · Rsbuild 2 / Rspack (сборка) ·
React 19 · TypeScript 6 · WebGL (собственные шейдеры, без библиотек) · oxlint/oxfmt.

| Что | Имя |
|---|---|
| Проект / npm-пакет | `yuka-agent-desktop-ui` |
| Бандл | `yuka-agent-desktop-ui.app` |
| Исполняемый файл, который ищет агент | `yuka-agent-desktop-ui.app/Contents/MacOS/yuka-agent-desktop-ui` |
| Результат сборки | `release/yuka-agent-desktop-ui.app` |
| Куда положить | каталог `gui/` рядом с бинарником агента |
| Имя в Dock и заголовок окна | «Юка» |

## 3. Сборка

```bash
npm run build
```

Команда собирает готовое приложение под ключ:

1. компилирует код (Rsbuild) в `dist/`;
2. упаковывает приложение (Forge), выставляет отображаемое имя «Юка» и заново
   подписывает бандл ad-hoc-подписью;
3. кладёт результат в **`release/yuka-agent-desktop-ui.app`**. Промежуточная папка
   `out/` удаляется, повторная сборка перезаписывает приложение.

Дальше приложение переносится вручную в каталог `gui/` рядом с бинарником агента
(в Finder или через `cp -R`):

```
<папка агента>/
├── yuka-agent
├── storage/default.json
└── gui/
    └── yuka-agent-desktop-ui.app
```

Приложение — это `.app`-бандл: исполняемый файл Electron не работает отдельно от своих
фреймворков и ресурсов. В Finder он выглядит как один файл. При пересылке через архив не
используйте `zip` без флага `-y`: он ломает символические ссылки внутри бандла.

## 4. Разработка

Два терминала: агент в режиме ожидания и приложение с горячей перезагрузкой интерфейса.

```bash
cd ../yuka-agent && YUKA_FACE=attach ./build/yuka-agent
```

```bash
npm run dev
```

Окно подключается к `/tmp/yuka-dev.sock`. Если перезапустить агент, окно
переподключится само. Изменения в `src/renderer` применяются сразу, а после изменений
в `src/main` или `src/preload` нужно перезапустить `npm run dev`.

Без агента приложение показывает экран «Юка спит».

| Скрипт | Что делает |
|---|---|
| `npm run dev` | Rsbuild dev-сервер + Electron (режим разработки) |
| `npm run build` | Готовое приложение в `release/yuka-agent-desktop-ui.app` |
| `npm run typecheck` | Проверка типов |
| `npm run lint` / `lint:fix` | oxlint и oxfmt |

## Дизайн: «Живое стекло»

Интерфейс как тонкий слой стекла над живым светом: глубина, точная типографика и
движение, которое ощущается физическим.

| Элемент | Как устроен |
|---|---|
| **Фон** | `AuroraBackground`: полноэкранный WebGL-шейдер с медленными потоками сияния (domain-warped fbm), зерном плёнки и лёгким параллаксом от курсора. Ночью мерцают звёзды, утром снизу поднимается тёплая дымка, вечером у горизонта светится закатная полоса. Рисуется в половинном разрешении, 30 fps |
| **Ядро Юки** | `YukaCore`: прозрачная стеклянная сфера на WebGL со светящимся заревом внутри. У стекла тонкая кромка с лёгкой дисперсией, резкий блик и отражённый свет снизу; зарево с горячим центром медленно дрейфует и дышит. Свет добавляется поверх фона (premultiplied alpha), поэтому фон виден сквозь стекло. Настроения: покой (тихое зарево), раздумье (зарево закручивается, по орбите бежит кольцо), речь (каждый пришедший кусок ответа разжигает зарево), сон (тлеет), нет связи (мерцание, холодный сдвиг). Клик по сфере в шапке переключает тему |
| **Окно** | Нативное стекло macOS (`vibrancy: 'under-window'`), фон слегка просвечивает. Светлая или тёмная схема окна следует за темой |
| **Стекло** | Размытие и насыщение подложки, тонкая граница, внутренний блик. Блик следует за курсором (`usePointerLight`) |
| **Шрифты** | Manrope — текст, а также логотип «ЮКА» и заголовки тонкой капителью с широкой разрядкой; JetBrains Mono — телеметрия, время, код. Всё с кириллицей и вшито в приложение |
| **Телеметрия** | Модель, скорость генерации (ток/с, считается по частоте кусков) и время до первого слова. Цифры прокручиваются, как в одометре |
| **Ответы** | Без пузыря, как редакционный текст со светящейся линией слева. Каждое новое слово проявляется из размытия. На конце строки, пока идёт ответ, бежит световой хвост |
| **Сообщения пользователя** | Стеклянные капсулы, появляются раскрытием справа |
| **Код** | Тёмное стекло, моноширинный шрифт, кнопка «копировать» с анимацией галочки |
| **Поле ввода** | Плавающая капсула. При фокусе по контуру бежит свет. Кнопка отправки: покой → готова → «выстрел» импульсом → ожидание ответа |
| **Заставки** | «Юка спит» (тлеющее ядро), «Просыпаюсь», «Связь потеряна» (стеклянное уведомление над лентой) |

### Темы

| Тема | Часы (местное время) | Настроение |
|---|---|---|
| Утро | 5:00–11:00 | рассвет: жемчуг, персик, бледная сирень, золото |
| День | 11:00–17:00 | ясность: белое стекло, лазурь, циан |
| Вечер | 17:00–22:00 | закат: слива, янтарь, коралл, маджента |
| Ночь | 22:00–5:00 | космос: индиго, северное сияние, звёзды |

Сменить тему можно двумя способами: кнопками переключателя в шапке или кликом по сфере (темы идут по кругу: утро → день → вечер → ночь). Переключатель: **Авто** (тема по часам, проверяется раз в 30 секунд) или
конкретная тема. Выбор сохраняется. Смена темы плавно перетекает примерно за 2 секунды:
цветовые токены зарегистрированы через `CSS.registerProperty`, а шейдеры интерполируют
свои параметры покадрово.

Все цвета описаны в одном месте, в `src/renderer/theme/themes.ts`. Оттуда их берут и
CSS-переменные `--c-*`, и шейдеры. Чтобы поменять часы тем, правьте `themeForHour()`
там же.

### Доступность и производительность

- Контраст рассчитан по реальной формуле смешивания шейдера, в худшей точке фона.
  Основной текст на стекле — не ниже 7.7:1, вторичный — не ниже 5.7:1, текст в
  капсулах — не ниже 7.7:1. Мелкие служебные подписи (время, телеметрия) — 3.6–4.3:1.
- `prefers-reduced-motion`: шейдеры замирают, слова появляются простым проявлением без
  размытия, остальные анимации отключены.
- Анимации интерфейса затрагивают только `transform`, `opacity` и `filter`. Шейдеры
  ограничены по частоте кадров и встают на паузу, когда окно скрыто. Во время потокового
  ответа интерфейс держит частоту экрана (на 120 Гц около 100 fps).
- Используются два WebGL-контекста (фон и ядро в шапке), третий — только на заставке.
  Маленькие ядра рядом с ответами нарисованы на CSS. Если WebGL недоступен, фон и ядро
  переключаются на CSS-градиенты.

## Устройство

```
yuka-agent (C++)  ── Unix-сокет, NDJSON ──▶  main (Electron)  ── IPC ──▶  renderer (React)
                                               └─ preload: window.yuka (contextBridge)
```

| Путь | Что внутри |
|---|---|
| `src/shared/protocol.ts` | Типы протокола агент ⇄ мордашка и IPC-каналы |
| `src/main/index.ts` | Окно, жизненный цикл, связь с агентом, безопасность |
| `src/main/agent-connection.ts` | NDJSON-клиент Unix-сокета (с переподключением в dev) |
| `src/preload/index.ts` | Минимальный типизированный мост `window.yuka` |
| `src/renderer/state/chat.ts` | Состояние чата (reducer), тайминги ответов и телеметрия |
| `src/renderer/theme/themes.ts` | Палитры и параметры сцены четырёх тем, часы тем |
| `src/renderer/theme/applyTheme.ts` | Регистрация `@property` и применение темы к документу |
| `src/renderer/theme/useTimeTheme.ts` | Режим «Авто» по часам, ручной выбор, сохранение |
| `src/renderer/theme/ThemeSwitcher.tsx` | Переключатель тем с перетекающей «каплей» |
| `src/renderer/gl/shaderLoop.ts` | Мини-движок WebGL: компиляция, размер, цикл кадров, пауза, шум |
| `src/renderer/components/AuroraBackground.tsx` | Живой фон (шейдер) |
| `src/renderer/components/YukaCore.tsx` | Ядро Юки (шейдер) и мини-ядро на CSS |
| `src/renderer/components/RichText.tsx` | Разметка ответа, пословное проявление, блоки кода |
| `src/renderer/components/RollingNumber.tsx` | Цифры-одометр для телеметрии |
| `src/renderer/hooks/usePointerLight.ts` | Позиция курсора для бликов на стекле |
| `src/renderer/styles/tokens.css` | Шрифты, отступы, радиусы, кривые и длительности анимаций |
| `src/renderer/styles/app.css` | Стили интерфейса |
| `rsbuild.config.mts` | Три окружения сборки: main и preload (Node, CommonJS), renderer (web) |
| `forge.config.mts` | Упаковка, имена бандла, Electron Fuses; хук `generateAssets` компилирует код, `postPackage` кладёт приложение в `release/` |

Безопасность: `contextIsolation`, `sandbox`, без `nodeIntegration`, строгий CSP,
запрет навигации и новых окон, Electron Fuses (без `RunAsNode`, загрузка только из asar).

Почему без плагина Forge для Rspack: официального плагина нет. Поэтому Rsbuild
собирает код, а Forge только упаковывает готовый `dist/`.

Почему `CFBundleName` остаётся `yuka-agent-desktop-ui`: по этому имени Electron ищет свои
вспомогательные процессы (`<CFBundleName> Helper.app`). Поэтому «Юка» выставляется только
в `CFBundleDisplayName`: его показывают Dock и Finder.
