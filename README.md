# Yuka Agent Desktop UI

Графическая «мордашка» для [Yuka Agent](../yuka-agent). Юка живёт **поверх всех программ**
стеклянной сферой без окна и рамки. Наведёшь на неё курсор — рядом появляется тонкая
ледяная панель диалога. Уберёшь курсор — через секунду панель плавно растворяется, а клик мимо закрывает её сразу.
Агент `yuka-agent` сам находит это приложение рядом с собой и ведёт разговор через него.

**Стек:** Electron 45 · Electron Forge 8 (упаковка) · Rsbuild 2 / Rspack (сборка) ·
React 19 · TypeScript 6 · WebGL (собственные шейдеры, без библиотек) · oxlint/oxfmt.

| Что                                  | Имя                                                              |
| ------------------------------------ | ---------------------------------------------------------------- |
| Проект / npm-пакет                   | `yuka-agent-desktop-ui`                                          |
| Бандл                                | `yuka-agent-desktop-ui.app`                                      |
| Исполняемый файл, который ищет агент | `yuka-agent-desktop-ui.app/Contents/MacOS/yuka-agent-desktop-ui` |
| Результат сборки                     | `release/yuka-agent-desktop-ui.app`                              |
| Куда положить                        | каталог `gui/` рядом с бинарником агента                         |
| Иконка в Dock                        | нет: Юка живёт поверх программ, а не в Dock                      |

## Как с ней обращаться

| Жест                   | Что происходит                                                                                                         |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Навести на сферу       | рядом появляется панель диалога                                                                                        |
| Увести курсор          | через 1 с панель плавно гаснет; вернёшься раньше — останется                                                           |
| Клик мимо Юки          | панель закрывается сразу                                                                                               |
| Клик по сфере          | панель скрыта — показать её всегда; открыта — закрепить / открепить                                                    |
| Перетащить сферу       | переместить Юку; место запоминается                                                                                    |
| Правый клик по сфере   | меню: «Показать диалог», «Вернуть Юку в угол», тема (Авто, Утро, День, Вечер, Ночь), «Закрепить панель», «Закрыть Юку» |
| `⌥ Space` (где угодно) | показать панель и сразу поставить курсор в поле ввода; ещё раз — спрятать                                              |
| `Esc` / `⌘W` в панели  | спрятать панель сразу                                                                                                  |
| `⌘Q` в панели          | закрыть Юку (и закончить сессию с агентом)                                                                             |

Пока ты печатаешь (в поле есть текст) или Юка отвечает, отсчёт 1 секунды стоит на паузе:
ответ не исчезнет на полуслове. Если ответ пришёл, когда панель была скрыта, сфера
мягко мигает двойной вспышкой, пока ты на неё не посмотришь.

Сфера и панель видны на всех рабочих столах и поверх полноэкранных приложений. Клики
мимо сферы проходят сквозь её окно к программам под ней.

### Надёжность окна

Панель не должна теряться никогда. Для этого main-процесс не доверяет ни событиям, ни
собственной памяти, а сверяется с фактом:

- **Наведение по факту.** Положение курсора опрашивается каждые 33 мс, и автомат
  присутствия (`presence.ts`) получает его на каждом тике, а не только при входе/выходе.
  Если курсор просто лежит на сфере, а панель почему-то закрыта, она откроется без
  движения мыши. Исключение — `Esc` под курсором: панель останется закрытой, пока курсор
  не уйдёт со сферы и панели и не вернётся.
- **Сверка на каждом тике.** `window-reconciler.ts` сравнивает, какой панель должна быть
  (по фазе автомата), с тем, какая она на самом деле: видима ли, непрозрачна ли, на
  экране ли, жива ли страница. Расхождение исправляется сразу: показать, поднять поверх
  всех окон, вернуть непрозрачность, вернуть на экран, перезагрузить страницу. Одно и то
  же исправление — не чаще раза в 500 мс. Сфера сверяется так же: она видна всегда.
- **Залипшие жесты.** Если нажатие на сферу «потерялось» (например, Ctrl+клик открыл
  меню и съел отпускание), через 3 с (перетаскивание — через 10 с) жест сбрасывается.
- **Потеря фокуса.** Панель не закрывается от потери фокуса, если курсор над Юкой или
  открыто её меню (⌘Tab с курсором на сфере ничего не ломает); в остальных случаях —
  через 300 мс.
- **Системные события.** После сна, разблокировки экрана, смены рабочего стола,
  подключения/отключения мониторов и возврата в приложение окна проверяются и
  возвращаются на место. Упавшая страница перезагружается.

Если панель всё же не видна — запасные выходы, каждый из которых показывает её
гарантированно: **клик по сфере**, **`⌥ Space`**, правый клик → **«Показать диалог»**.
Если потерялась сама сфера (например, после отключения монитора) — правый клик →
**«Вернуть Юку в угол»** или `⌥ Space`.

**Журнал.** Все решения окон пишутся в stdout; агент сохраняет его в
`/tmp/yuka-face-yuka-agent-desktop-ui.log`. Формат строки — время, категория, событие:

```
2026-11-06T12:00:00.123Z [presence] hidden→shown reason=pointer orb=true panel=false
2026-11-06T12:00:05.456Z [reconcile] panel: show,reassert,opaque (want visible, was hidden)
```

Категории: `presence` (смена фазы и причина), `reconcile` (что исправлено), `gesture`
(нажатия и сброс залипших), `focus`, `system` (сон, рабочие столы, мониторы), `renderer`
(падения и перезагрузки страниц). Одинаковые строки подряд сворачиваются в
«…повторилось N раз». Если панель пропала, смотри последние строки:

```bash
tail -n 50 /tmp/yuka-face-yuka-agent-desktop-ui.log
```

## Юка управляет интерфейсом сама

Мордашка объявляет агенту свои **инструменты** (протокол v2, форма сообщений как в MCP,
см. [`../yuka-agent/docs/face-protocol.md`](../yuka-agent/docs/face-protocol.md)). Когда ты
просишь «включи ночную тему», модель решает вызвать `ui_set_theme`, агент пересылает вызов
сюда, а мордашка выполняет его и сообщает результат.

| Инструмент      | Аргументы                                                           | Что делает                                     |
| --------------- | ------------------------------------------------------------------- | ---------------------------------------------- |
| `ui_get_state`  | —                                                                   | тема, открыта/закреплена ли панель, угол сферы |
| `ui_set_theme`  | `mode`: `auto` / `morning` / `day` / `evening` / `night`            | меняет тему                                    |
| `ui_pin_panel`  | `pinned`: `true` / `false`                                          | закрепляет или открепляет панель               |
| `ui_hide_panel` | —                                                                   | прячет панель                                  |
| `ui_move_orb`   | `corner`: `top_left` / `top_right` / `bottom_left` / `bottom_right` | переносит сферу в угол экрана                  |
| `ui_quit`       | —                                                                   | закрывает Юку — **только после «Да»** в панели |

- Аргументы проверяются по JSON Schema инструмента. Ошибка возвращается модели понятным
  текстом, и она может исправить вызов.
- Пока действие выполняется, в ленте видна тихая строка «Сменить тему…», затем она
  становится «✓ Тема: ночь.». Сфера коротко вспыхивает.
- Опасное действие (`destructiveHint`) показывает в ленте карточку «Юка хочет закрыться.
  Закрыть? [Да] [Нет]». Панель открывается сама. Без ответа за 55 секунд считается «нет».
- Старый агент (без `protocol: 2` в `hello`) инструментов не получает — всё работает как раньше.

### Как добавить инструмент

1. Описание — в `src/main/tools/ui-tools.ts`: `name` (`ui_…`), `title`, `description` для
   модели (когда вызывать и когда **не** вызывать), `inputSchema` со строгими `enum` и
   `additionalProperties: false`, `annotations`.
2. Исполнение — ветка в `UiToolHost.run()` (`src/main/tools/ui-tool-host.ts`) и, если нужно,
   метод в `UiController` / `WindowManager`. Результат — короткий русский текст для модели.
3. Тест — в `tests/ui-tools.test.ts`.

Агент пересобирать не нужно: новый инструмент он получит при следующем подключении.

## 3. Сборка

```bash
npm run build
```

Команда собирает готовое приложение под ключ:

1. компилирует код (Rsbuild) в `dist/`;
2. упаковывает приложение (Forge), выставляет отображаемое имя «Юка» и заново
   подписывает бандл ad-hoc-подписью;
3. кладёт результат в **`release/yuka-agent-desktop-ui.app`**. Промежуточная папка
   `out/` удаляется, повторная сборка перезаписывает приложение.

Дальше приложение переносится вручную в каталог `gui/` рядом с бинарником агента
(в Finder или через `cp -R`):

```
<папка агента>/
├── yuka-agent
├── config/default.json
└── gui/
    └── yuka-agent-desktop-ui.app
```

Приложение — это `.app`-бандл: исполняемый файл Electron не работает отдельно от своих
фреймворков и ресурсов. В Finder он выглядит как один файл. При пересылке через архив не
используйте `zip` без флага `-y`: он ломает символические ссылки внутри бандла.

## 4. Разработка

Два терминала: агент в режиме ожидания и приложение с горячей перезагрузкой интерфейса.

```bash
cd ../yuka-agent && YUKA_FACE=attach ./build/yuka-agent
```

```bash
npm run dev
```

Сфера подключается к `/tmp/yuka-dev.sock`. Если перезапустить агент, она
переподключится сама. Изменения в `src/renderer` применяются сразу, а после изменений
в `src/main` или `src/preload` нужно перезапустить `npm run dev`.

Без агента сфера тлеет, а панель пишет «Юка спит — запусти yuka-agent».

| Скрипт                      | Что делает                                               |
| --------------------------- | -------------------------------------------------------- |
| `npm run dev`               | Rsbuild dev-сервер + Electron (режим разработки)         |
| `npm run build`             | Готовое приложение в `release/yuka-agent-desktop-ui.app` |
| `npm test`                  | Тесты (автомат, геометрия, инструменты, подтверждения)   |
| `npm run typecheck`         | Проверка типов                                           |
| `npm run lint` / `lint:fix` | oxlint и oxfmt                                           |

## Дизайн

| Элемент          | Как устроен                                                                                                                                                                                                                                                                                                             |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Сфера**        | WebGL-шейдер на полностью прозрачном холсте: стекло с френелевой кромкой, бликом и каустикой, внутри дрейфует и дышит зарево. Кромка сглажена аналитически (≈1.2 физических пикселя при любом масштабе), поэтому выглядит вырезанной, как SVG. Ореол затухает до нуля раньше края окна — квадрата окна не видно никогда |
| **Настроения**   | покой — медленное дыхание (5 с); думает — зарево закручивается, по орбите бежит кольцо (2 с); отвечает — пульс от каждого куска ответа (1.3 с); спит — тлеет; нет связи — холодное мерцание; непрочитанное — двойная вспышка раз в 2.4 с; под курсором — чуть ярче                                                      |
| **Лёд**          | Окно панели — нативная vibrancy macOS (`popover`): настоящее размытие того, что под ним. Поверх — едва заметный тон темы, срезанная кромка (светлая сверху, темнее снизу), диагональный блик и матовое зерно                                                                                                            |
| **Появление**    | Окно проявляется по прозрачности (main, 260 мс), содержимое выплывает со стороны сферы: прозрачность, масштаб 0.965 → 1, размытие 6 → 0 px                                                                                                                                                                              |
| **Исчезновение** | В обратную сторону за 420 мс с ускорением. Черновик в поле ввода сохраняется                                                                                                                                                                                                                                            |
| **Размер**       | Ширина 352 px, высота растёт вместе с разговором от 132 до 520 px. Панель встаёт слева от сферы (низ по низу), у края экрана — справа, сверху или снизу                                                                                                                                                                 |
| **Разговор**     | Ответы Юки — просто текст на льду, каждое слово проявляется из размытия; твои сообщения — маленькие капсулы справа; время — при наведении; код — в матовых блоках с кнопкой «копировать»; «думает» — маленькая сфера                                                                                                    |

### Темы

| Тема  | Часы (местное время) | Настроение                                      |
| ----- | -------------------- | ----------------------------------------------- |
| Утро  | 5:00–11:00           | рассвет: жемчуг, персик, бледная сирень, золото |
| День  | 11:00–17:00          | ясность: белое стекло, лазурь, циан             |
| Вечер | 17:00–22:00          | закат: слива, янтарь, коралл, маджента          |
| Ночь  | 22:00–5:00           | космос: индиго, северное сияние                 |

Тема выбирается в меню сферы (правый клик): **Авто** (по часам) или конкретная. Выбор
сохраняется. Смена плавно перетекает: цвета зарегистрированы через `CSS.registerProperty`,
шейдер интерполирует свои параметры покадрово. Светлая или тёмная схема льда (vibrancy)
следует за темой.

Все цвета — в `src/renderer/theme/themes.ts` (оттуда берут и CSS-переменные `--c-*`, и
шейдер).

### Доступность и производительность

- `prefers-reduced-motion`: сфера только дышит, слова появляются простым проявлением.
- Сфера рисует 30 fps в покое и 60 fps, когда она под курсором, думает, отвечает или
  мигает. Когда окно не видно, цикл стоит на паузе.
- Положение курсора main опрашивает 30 раз в секунду (во время перетаскивания — около 120).
- Если WebGL недоступен, сфера рисуется CSS-градиентами.

## Устройство

```
yuka-agent (C++) ── Unix-сокет, NDJSON ──▶ main (Electron) ── IPC ──▶ окно сферы  (?view=orb)
                                             │                    └─▶ окно панели (?view=panel)
                                             └─ preload: window.yuka (contextBridge)
```

Main хранит весь разговор (`SessionHub`) и рассылает его обоим окнам. Окно, которое
перезагрузилось, получает журнал заново, поэтому сфера и панель всегда согласованы. Когда
показывать панель, решает чистый автомат `presence.ts`. Наведение определяет main по
геометрии (курсор относительно круга сферы и прямоугольника панели), а не по DOM-событиям
двух разных окон.

| Путь                                    | Что внутри                                                                                                                                       |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src/shared/protocol.ts`                | Протокол агент ⇄ мордашка, UI-состояние, IPC-каналы, API `window.yuka`                                                                           |
| `src/shared/geometry.ts`                | Размеры сферы и панели, попадание в круг, где встаёт панель, удержание на экране (чистые функции)                                                |
| `src/main/index.ts`                     | Сборка частей: связь с агентом, журнал сессии, окна, IPC                                                                                         |
| `src/main/agent-connection.ts`          | NDJSON-клиент Unix-сокета (с переподключением в dev)                                                                                             |
| `src/main/session-hub.ts`               | Журнал разговора, доставка и повтор в оба окна, «Юка занята», «ответ готов»                                                                      |
| `src/main/presence.ts`                  | Автомат «показана / отсчёт 1 с / гаснет / скрыта» (чистый, с тестами)                                                                            |
| `src/main/ipc.ts`                       | IPC-обработчики с проверкой окна-отправителя и аргументов                                                                                        |
| `src/main/tools/ui-tools.ts`            | Каталог инструментов интерфейса и инструкция для модели (`capabilities`)                                                                         |

| `src/main/tools/schema.ts`              | Мини-валидатор JSON Schema для аргументов                                                                                                        |
| `src/main/confirmations.ts`             | Вопросы «Да / Нет» перед опасными действиями                                                                                                     |
| `src/main/settings-store.ts`            | `userData/ui-state.json`: положение сферы, режим темы                                                                                            |
| `src/main/diagnostics.ts`               | Журнал решений окон (`presence`, `reconcile`, `gesture`, …) со сворачиванием повторов                                                            |
| `src/main/windows/window-manager.ts`    | Опрос курсора, click-through, автомат, сверка окон, восстановление после сна/рабочих столов/мониторов, анимации, перетаскивание, меню, `⌥ Space` |
| `src/main/windows/window-reconciler.ts` | Сверка «какой окно должно быть» с «какое оно есть», ограничитель частоты, залипшие жесты (чистый, с тестами)                                     |

| `src/main/windows/panel-window.ts`      | Окно панели с vibrancy                                                                                                                           |

| `src/main/windows/opacity-animator.ts`  | Плавная прозрачность окна (CSS не гасит нативную vibrancy)                                                                                       |
| `src/preload/index.ts`                  | Минимальный типизированный мост `window.yuka`                                                                                                    |
| `src/renderer/views/OrbView.tsx`        | Сфера: клик, перетаскивание, меню                                                                                                                |
| `src/renderer/views/PanelView.tsx`      | Панель: лента, статус связи, поле ввода, авто-высота, Esc                                                                                        |
| `src/renderer/components/Orb.tsx`       | Шейдер сферы и мини-сфера на CSS                                                                                                                 |
| `src/renderer/components/RichText.tsx`  | Разметка ответа, пословное проявление, блоки кода                                                                                                |
| `src/renderer/state/chat.ts`            | Состояние разговора (reducer) и настроение сферы                                                                                                 |
| `src/renderer/theme/`                   | Палитры, применение темы, режим «Авто»                                                                                                           |
| `src/renderer/gl/shaderLoop.ts`         | Мини-движок WebGL: компиляция, размер, цикл кадров с переменной частотой                                                                         |
| `src/renderer/styles/`                  | `tokens`, `base`, `orb`, `panel`, `messages`                                                                                                     |
| `tests/`                                | Тесты автомата присутствия, сверки окон, сценариев восстановления, журнала, геометрии, инструментов и подтверждений (`npm test`)                 |
| `rsbuild.config.mts`                    | Три окружения сборки: main и preload (Node, CommonJS), renderer (web)                                                                            |
| `forge.config.mts`                      | Упаковка, имена бандла, Electron Fuses; `postPackage` кладёт приложение в `release/`                                                             |

Безопасность: `contextIsolation`, `sandbox`, без `nodeIntegration`, строгий CSP,
запрет навигации и новых окон, IPC принимается только от своих окон, Electron Fuses
(без `RunAsNode`, загрузка только из asar).

Почему без плагина Forge для Rspack: официального плагина нет. Поэтому Rsbuild
собирает код, а Forge только упаковывает готовый `dist/`.

Почему `CFBundleName` остаётся `yuka-agent-desktop-ui`: по этому имени Electron ищет свои
вспомогательные процессы (`<CFBundleName> Helper.app`). Поэтому «Юка» выставляется только
в `CFBundleDisplayName`: его показывает Finder.
